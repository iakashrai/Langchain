# Apache Kafka
* Apache Kafka is a powerful **distributed event streaming platform** used by thousands of modern companies.
* It was originally created by software engineers at **LinkedIn in 2011** before being open-sourced through the Apache Software Foundation.
* The platform was intentionally **named after the author Franz Kafka** because the system is heavily optimized for writing data.
* It operates as a high-performance **publish-subscribe messaging system** that handles continuous feeds of information.
* The architecture relies heavily on **producers** that generate data and **consumers** that read it in real time.
* All incoming data records are organized and stored into specific categories known as **topics**.
* To scale efficiently, these topics are split into **partitions**, allowing messages to be safely processed in parallel.
* It is built to offer **high throughput**, making it fully capable of managing millions of incoming messages every second.
* Because it is a **distributed system**, it runs across clusters of servers called brokers to guarantee exceptional fault tolerance.
* Unlike traditional messaging lines that delete read data, Kafka is **durable** and stores records permanently on hard drives for a designated time.
